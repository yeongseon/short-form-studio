## Getting Started

### Access URLs

- **Studio Web UI**: `http://localhost:5174`
- **API**: `http://localhost:8000` (internal prefix: `/api/creator`)

### Starting Services

```bash
cd short-form-studio
docker compose up -d
```

Required services: `postgres`, `redis`, `api`, `worker`, `studio-web`

For frontend live-reload during development, run the frontend directly:

```bash
cd apps/studio-web
npm run dev
```

Optional services (GPU required):
- `stable-diffusion` — Image generation (6GB+ VRAM)
- `tts-qwen3` — TTS voice generation
- `stt-whisper` — Subtitle generation (Whisper small, configurable)

> ⚠️ On a GPU with limited VRAM (e.g. GTX 1660 SUPER 6GB), you cannot run all GPU services simultaneously. Start only the services you need.

## Creating a Project

Click the **"Create New Project"** button in the Studio Web UI. Two tabs are available:

> The current UI supports two starting modes: **Idea** and **JSON**.
> `URL` and `Markdown` source types may still exist in internal contracts but are not supported in the current user flow.

### Tab 1: Start from Idea

The AI automatically generates a script from your idea.

| Field | Required | Description |
|-------|----------|-------------|
| **Title** | ✅ | Project title |
| **Idea Brief** | ✅ | Video idea description (free-form) |
| **Target Duration** | - | Target length in seconds (default: 60, range: 10–180) |
| **Content Goal** | - | Content goal (e.g. educational, entertainment) |

→ Clicking "Create Project": creates the project → AI generates a script → redirects to the project page

### Tab 2: Start from JSON

Paste a JSON script (e.g. generated by ChatGPT).

| Field | Required | Description |
|-------|----------|-------------|
| **Title** | - | Project title (defaults to "Untitled" if empty) |
| **JSON Script** | ✅ | Scene script in JSON format (paste directly or upload a file) |

→ You can also upload `.json` or `.txt` files.

#### JSON Script Format

```json
{
  "scenes": [
    {
      "type": "hook",
      "text": "Can you believe AI can create a video in just 60 seconds?",
      "image_prompt": "A futuristic holographic AI interface creating video content...",
      "speaker": "host",
      "mood": "exciting",
      "composition": "medium shot, centered",
      "style_tags": ["cinematic", "sci-fi"]
    }
  ]
}
```

| Field | Required | Description |
|-------|----------|-------------|
| `type` | ✅ | Scene type (hook, body, cta, etc.) |
| `text` | ✅ | Narration/script text |
| `image_prompt` | - | Image generation prompt (used first in the visual plan) |
| `speaker` | - | Speaker (e.g. host, narrator) |
| `mood` | - | Mood (e.g. exciting, calm) |
| `composition` | - | Composition (e.g. close-up, wide shot) |
| `style_tags` | - | List of style tags |
| `display_text` | - | On-screen display text (subtitle override) |
| `duration` | - | Scene duration in seconds |

### Common Settings

- **Model Defaults**: Select models for script/image generation per category
- **Style Preset**: Choose from `default`, `cinematic`, `dynamic`, `minimal`

## Pipeline Stages

After project creation, the pipeline progresses automatically:

```
IDEA_READY → SCRIPT_GENERATING → SCRIPT_REVIEW
    → VISUAL_PLAN_GENERATING → VISUAL_PLAN_REVIEW
    → VISUAL_ASSET_GENERATING → VISUAL_ASSET_REVIEW
    → AUDIO_GENERATING → SUBTITLE_GENERATING
    → RENDER_GENERATING → FINAL_REVIEW
```

| Stage | Description | Model Used |
|-------|-------------|------------|
| **SCRIPT_GENERATING** | Generate script from idea (skipped for JSON input) | Ollama (qwen3:4b) |
| **SCRIPT_REVIEW** | Review and approve the generated script | - |
| **VISUAL_PLAN_GENERATING** | Generate visual plan (prompts) per section | Ollama (qwen3:4b) |
| **VISUAL_PLAN_REVIEW** | Review and approve the visual plan | - |
| **VISUAL_ASSET_GENERATING** | Generate images | Stable Diffusion (local) |
| **VISUAL_ASSET_REVIEW** | Review and approve generated images | - |
| **AUDIO_GENERATING** | Convert script text to speech (TTS) | Qwen TTS (local) |
| **SUBTITLE_GENERATING** | Generate subtitles (SRT) from audio | Whisper small (local, configurable) |
| **RENDER_GENERATING** | Combine images + audio + subtitles into final video | FFmpeg |
| **FINAL_REVIEW** | Review the final video | - |

---

## Review and Approval

At each `_REVIEW` stage you can **Approve** or **Reject**.

### Project Page

The project page shows the current pipeline stage and review status.
- **Approve**: Automatically advances to the next stage
- **Reject**: Regenerates the current stage

### Review Page

When the pipeline reaches `FINAL_REVIEW`, an **"Open Review Page"** link appears.
The review page shows all generated assets at a glance:
- Full script
- Visual plan
- Generated images (per section)
- Audio playback
- Subtitles (SRT)
- Final rendered video playback

## Model Configuration

### Default Local Models

| Category | Model | Description |
|----------|-------|-------------|
| **LLM (Script/Plan)** | `qwen3:4b` (Ollama) | Script and visual plan generation |
| **Image** | Stable Diffusion (local) | Image generation via SD WebUI |
| **TTS** | Qwen TTS (local) | Text-to-speech conversion |
| **STT** | Whisper small (local, configurable) | Speech-to-text for subtitles |

### Model Selection

When creating a project, you can select models per category in the **"Model Defaults"** section.
Both local models and external API providers are supported. See [External API Providers](#external-api-providers) for details.

## External API Providers

You can use external APIs for higher-quality results instead of (or in addition to) local models.

### Supported Providers

| Category | Provider | Model | Environment Variable |
|----------|----------|-------|---------------------|
| **LLM** | OpenAI | GPT-4o Mini | `OPENAI_API_KEY` |
| **LLM** | Anthropic | Claude Sonnet | `ANTHROPIC_API_KEY` |
| **LLM** | Google | Gemini 2.0 Flash | `GOOGLE_API_KEY` |
| **Image** | OpenAI | DALL-E 3 | `OPENAI_API_KEY` |
| **Image** | Stability AI | SD3 Medium | `STABILITY_API_KEY` |
| **Image** | Google | Imagen 3 | `GOOGLE_API_KEY` |
| **TTS** | ElevenLabs | Multilingual v2 | `ELEVENLABS_API_KEY` |
| **TTS** | OpenAI | TTS-1 | `OPENAI_API_KEY` |

### Setting Up API Keys

The Settings page is currently a **read-only status page** — it does not support editing or saving API keys.
You can check whether each provider key is configured at `/settings`, but actual key values are managed via server environment variables.

#### Editing the .env File

Add your API keys to the `.env` file:

```bash
OPENAI_API_KEY=sk-your-openai-key
ANTHROPIC_API_KEY=sk-ant-your-anthropic-key
GOOGLE_API_KEY=your-google-api-key
STABILITY_API_KEY=sk-your-stability-key
ELEVENLABS_API_KEY=your-elevenlabs-key
```

> ⚠️ After setting or changing API keys, restart the API and worker: `docker compose restart api worker`

### Model Selection

When creating a project, select between local and remote models in the **Model Defaults** section.
- **Local**: Requires GPU services, free, slower
- **Remote**: Requires API keys, paid, faster and higher quality

If a ⚠️ icon appears next to a remote model, the corresponding provider API key is not configured.

#### Model Key vs Provider Model Name

The Studio uses **model keys** (logical identifiers) that map to provider-specific model names:

| Model Key (API/UI) | Provider | Actual Model Name |
|---|---|---|
| `qwen3-4b` | Ollama | `qwen3:4b` |
| `sd15` | Stable Diffusion | SD 1.5 |
| `whisper-small` | Whisper | `small` |
| `gpt-4o-mini` | OpenAI | `gpt-4o-mini` |
| `claude-sonnet` | Anthropic | `claude-sonnet-4-20250514` |
| `dalle-3` | OpenAI | `dall-e-3` |

Model keys use hyphens (not colons) and are always lowercase.

## Generated File Locations

All generated assets are stored in the `data/artifacts/<run_id>/` directory:

```
data/artifacts/<run_id>/
├── scenes/
│   ├── scene-hook-1.png        # Per-section images
│   ├── scene-body-1.png
│   └── ...
├── audio/
│   └── audio.wav               # TTS-generated audio
├── subtitles/
│   └── subtitles.srt           # Whisper-generated subtitles
└── render/
    └── output.mp4              # Final rendered video (1080x1920, H.264, 30fps)
```

## Limitations

### GPU Memory

- GPU: NVIDIA GeForce GTX 1660 SUPER (6GB VRAM)
- GPU services (Stable Diffusion, TTS, STT) cannot run simultaneously
- A GPU lock is used — one GPU task must complete before the next can start

### Worker

- The development Docker Compose override (`docker-compose.dev.yml`) uses `watchfiles` which may restart the worker on file changes
- For stable execution, use a standalone worker:

```bash
docker compose run -d --name sfp-worker-direct --no-deps \
  -e REDIS_URL=redis://redis:6379/0 \
  -e DATABASE_URL=postgresql://short_form_user:short_form_password@postgres:5432/short_form_studio \
  -e OLLAMA_BASE_URL=http://ollama:11434 \
  -e STABLE_DIFFUSION_BASE_URL=http://stable-diffusion:7860 \
  -e TTS_QWEN3_BASE_URL=http://tts-qwen3:8100 \
  -e STT_WHISPER_BASE_URL=http://stt-whisper:8200 \
  -e ARTIFACT_ROOT=data/artifacts \
  -e GPU_LOCK_KEY=gpu:lock \
  -e GPU_LOCK_TIMEOUT_SECONDS=600 \
  -e PYTHONPATH=/app/src:/app \
  worker celery -A celery_app.celery_app worker --loglevel=info --pool=solo
```

### Networking

- Studio Web and API run on the same Docker network
- Studio Web is bound to localhost by default: `http://localhost:5174`
- The Vite proxy automatically forwards `/api` requests to the API server

### Rendering

- Video rendering uses FFmpeg and runs locally
- Output format: 1080x1920 (portrait), H.264 codec, 30fps
- Subtitles are burned into the video
